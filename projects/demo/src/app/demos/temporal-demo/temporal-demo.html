Temporal

Cinq champs de saisie adossés à l'API Temporal (typage fort, jamais de Date) : <kt-date-field> (PlainDate), <kt-time-field> (PlainTime), <kt-date-time-field> (PlainDateTime), <kt-year-month-field> (PlainYearMonth) et <kt-instant-field> (Instant UTC affiché en heure locale via KtClock). Pickers natifs HTML5, parsing tolérant (saisie invalide → null, jamais d'exception), intégration Signal Forms (FormValueControl). Accessibilité héritée du système champ : libellé associé (<label for>), aria-describedby, région live pour l'erreur, cibles tactiles 44px (AAA).

Date complète : {{ today() | temporalDate: { dateStyle: 'full' } }}

Mois & année : {{ today() | temporalDate: { month: 'long', year: 'numeric' } }}

Instant en heure locale : {{ recordedAt() | temporalDate: { dateStyle: 'medium', timeStyle: 'short' } }}
