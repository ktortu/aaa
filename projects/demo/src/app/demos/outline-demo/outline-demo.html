Apparence outline

Pour vous faciliter la vie si vous migrez depuis une interface Angular Material, tous les champs (kt-text-field, kt-select, champs temporels...) supportent l'apparence outline. C'est idéal pour faire une transition en douceur sans bousculer vos habitudes visuelles. Le style par défaut reste fill, l'apparence outline est donc optionnelle.

Le label flotte (se loge dans la bordure) dès qu'une de ces conditions est vraie, en CSS pur :

  • Focus — :focus-within sur le champ.
  • Input rempli — :has(input:not(:placeholder-shown)). En outline, les champs à input posent une sentinelle de placeholder (une espace) pour rendre l'état « rempli » détectable même sans placeholder visible.
  • Contrôle non-input rempli — le kt-select (dont le trigger est un <button>) expose data-filled quand une option est sélectionnée ; son placeholder propre est masqué en outline (le label tient lieu de placeholder).

Les champs date/heure n'ont pas de placeholder CSS (ils affichent leur format natif) : leur label reste donc toujours flotté — cohérent, un champ date n'a pas d'état « vide visuel ». L'animation respecte prefers-reduced-motion, le rendu suit le sens dir (RTL) et le contraste forcé (Windows High Contrast).

À noter : avec une icône/préfixe en tête, le label au repos (position « placeholder ») se cale sur le bord du champ et peut chevaucher l'icône tant qu'il n'a pas flotté. Préférez alors floatLabel="always" (label toujours en haut) ou une icône en suffixe.
