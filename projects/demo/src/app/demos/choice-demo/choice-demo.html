Checkbox / Radio / Switch

Trois contrôles de choix accessibles : <kt-switch> (interrupteur role="switch", valeur boolean), <kt-checkbox> (case bâtie sur un <input type="checkbox"> natif, état indeterminate) et <kt-radio> (au sein d'un <kt-radio-group>, <input type="radio"> natifs partageant le name → clavier roving + flèches gratuits). Intégrés aux Signal Forms via FormValueControl. Accessibilité : libellé associé, légende de groupe (role="group"/"radiogroup", aria-labelledby), aria-required/aria-invalid, région live pour l'erreur, cibles tactiles 44px (AAA) et support du mode contraste élevé.
