Select

<kt-select> est un « select-only combobox » WAI-ARIA bâti sur @angular/aria : choix unique dans une liste fermée, sans saisie libre. Présentation responsive via un seul Popover (top-layer) : dropdown ancré sur desktop, bottom-sheet modale sur téléphone (focus roving, cibles ≥44px, scrim, drag-to-dismiss). Filtrage opt-in avec annonce live du nombre de résultats, fermeture au Échap / clic extérieur / Tab (APG). Composé avec Field et intégrable aux Signal Forms via FormValueControl.
