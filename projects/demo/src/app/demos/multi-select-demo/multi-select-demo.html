Multi-Select

<kt-multi-select> est un combobox de sélection multiple (WCAG 2.2 AAA / RGAA) bâti sur @angular/aria avec [multi]="true". Le trigger affiche un résumé textuel et les choix se matérialisent en chips révocables sous le champ (focus management, repli +N, région live délégués à kt-chip-list). Présentation adaptative (dropdown desktop ↔ bottom-sheet téléphone). Clavier APG : Espace/Entrée togglent, Shift+flèches étend la plage, Ctrl+A (dé)sélectionne tout, typeahead. Options de masse (« Tout sélectionner / Tout effacer ») et filtre opt-in.
