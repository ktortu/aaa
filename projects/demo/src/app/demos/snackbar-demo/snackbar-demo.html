Service & API

Snackbar

Feedback non bloquant qui confirme une action ou signale un événement transitoire sans interrompre la tâche. Ouverte par le service KtSnackbar.open(message, options?), montée dans l’overlay CDK et annoncée via le LiveAnnouncer — un seul canal d’annonce (le panneau n’est pas une live region), ce qui évite la double-annonce et l’écrasement de politesse. Accessibilité : le focus n’est jamais déplacé (RGAA « message de statut » / WCAG 4.1.3), disparition automatique en pause au survol et au focus (WCAG 1.4.13 / 2.2.1) ou persistante en timing: 'manual' (AAA 2.2.3), bouton de fermeture cible 44px, Échap pour fermer, respect de prefers-reduced-motion. File FIFO : une seule snackbar visible, les suivantes patientent (file bornée à 3, messages identiques fusionnés). La snackbar ne porte pas d’action interactive (un bouton dans une live region n’est pas atteignable) : pour un undo ou une information critique à acquitter, préférez le dialog.
